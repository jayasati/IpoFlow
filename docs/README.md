# IPOFlow

A personal web application to manage IPO investments for multiple members.

Purpose:
- Manage members
- Send money
- Track IPO applications
- Track allotments
- Calculate profit/loss
- Calculate member commission
- Maintain wallet & ledger
- Track money returns

Stack

Frontend
- React
- Vite
- TypeScript
- TailwindCSS

Backend
- Express
- Prisma
- MySQL

The application is desktop-first and optimized for fast workflows.
