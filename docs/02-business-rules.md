# Business Rules

- One member can participate once per IPO.
- Wallet balance is never stored.
- Wallet is calculated from ledger.
- Ledger is immutable.
- Commission is only charged on profit.
- Loss has zero commission.
- Every financial event creates one ledger entry.
- Outstanding amount = Wallet Balance.

Wallet

Wallet = Credits - Debits

Credits

- Money Sent
- IPO Profit
- Adjustment

Debits

- Money Returned
- IPO Loss
- Commission
- Adjustment
